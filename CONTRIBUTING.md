# Contributing to DUF
## Authority
Malachi Dawkins is the final creative and canon authority.
## Before Adding Content
Confirm:
1. which DUF directory owns the material;
2. whether it is Active Canon, Proposed, Draft, Retired, or Obsidian;
3. whether it affects shared continuity;
4. whether a Malachi ruling is required;
5. whether the content belongs in DUF or another WiseMinds project.
## File Header
Canon-bearing Markdown files should begin with:
```yaml
---
project: DUF
title:
status: Draft
version: 0.1
owner: WiseMinds Studios
final_authority: Malachi Dawkins
source:
last_verified:
---
```
## Shared Continuity
Do not redefine:
- Gideon Cross;
- PHΔDE CELL;
- Major Trammell;
- Crossroads Earth;
- universal Doom Stone laws;

without an approved cross-project ruling.
## Obsidian Locks
Do not reveal or complete protected mysteries.
## Pull Requests
Every pull request should state:
- work completed;
- canon status;
- locked decisions preserved;
- contradictions found;
- Malachi rulings required;
- files changed;
- source documents used.
